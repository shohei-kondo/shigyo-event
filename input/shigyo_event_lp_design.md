# 士業団体向けイベント幹事サポートLP 設計メモ

## 1. このLPの目的

本LPは、士業団体・支部・研究会などのイベント幹事に向けて、イベント準備の一部を支援するサービスを案内するためのLPである。

表向きの訴求は、あくまで以下とする。

> 士業団体・支部イベントの幹事業務を、必要なところだけお手伝いします。

一方で、事業上の背景としては、士業の方々との接点を作り、将来的に士業の先にいる法人・顧問先企業との案件につなげる入口として位置づける。

ただし、この「士業経由で法人案件につなげたい」という意図はLP上では前面に出さない。  
まずは、士業団体自身のイベント幹事業務を支援するサービスとして自然に見せる。

---

## 2. 基本方針

今回のLP設計方針は以下の通り。

- 業種別に個別URLを作る
- ユーザーには1ページだけ見せる
- その業界に特化している印象を出す
- サービスは3つに絞る
- 価格は無料・2万円・3万円で軽く見せる
- 裏目的である士業との関係づくりは、LP上では出しすぎない

---

## 3. 想定ターゲット

### 表向きのターゲット

士業団体・支部・研究会・協会などのイベント幹事担当者。

具体例：

- 弁護士会・弁護士協会の支部幹事
- 税理士会の支部幹事
- 社労士会の支部幹事
- 司法書士会、行政書士会などの研究会・交流会担当者
- 不動産鑑定士協会などの懇親会・研修後交流会担当者

### ターゲットが抱える課題

- 持ち回りで幹事が回ってきた
- 本業が忙しく、会場探しや台本作成に時間をかけられない
- 毎年同じ会場・同じ進行になっている
- 何を準備すべきか分からない
- 先生方に失礼のない会場や進行にしたい
- イベント会社に丸投げするほどではない
- ただし、幹事だけで全部抱えるのは負担が大きい

---

## 4. LPのユーザー体験設計

### 重要な考え方

ユーザー自身に「どの業種向けページを見るか」を選ばせない。

営業側が、相手に合わせて個別URLを送る。

そのため、ユーザーから見ると以下のように感じられる状態を目指す。

> 自分たちの業界・団体向けに作られたサービスページだ。

### 例

弁護士会関係者に送るURL：

```text
/shigyo-event/lawyer/
```

税理士会関係者に送るURL：

```text
/shigyo-event/tax-accountant/
```

ユーザーはゲートウェイページで業種を選ぶのではなく、最初から自分たち向けの個別LPを見る。

## 5. 初期スコープ

初期制作では、以下の構成に絞る。

```text
/shigyo-event/
  ├─ /lawyer/
  └─ /tax-accountant/
```

| ページ | 役割 | 外部への見せ方 |
|---|---|---|
| ゲートウェイページ | 管理用・営業側の分岐用 | 原則、積極的には見せない |
| 弁護士会向けLP | 弁護士会・支部イベント向けの特化ページ | 弁護士系の営業先に送る |
| 税理士会向けLP | 税理士会・支部イベント向けの特化ページ | 税理士系の営業先に送る |

初期は、弁護士会向け・税理士会向けの2ページで様子を見る。  
理由は、いずれも法人顧客との接点が強く、将来的な紹介導線につながりやすいため。

## 7. LPの基本構成

個別LPの構成は、士業別に大きく変えない。  
本文は8〜9割共通化し、タイトル・冒頭文・イベント例・一部表現のみ差し替える。

### 構成案

1. ファーストビュー
2. 共感パート
3. サービス内容
4. プラン・料金
5. 利用シーン
6. ご相談の流れ
7. よくある相談例
8. 問い合わせ導線

## 10. サービス内容

サービスは3つに絞る。

| プラン | 内容 | 価格 |
|---|---|---:|
| 企画の無料相談 | イベント内容・進行・景品・会場条件などの壁打ち | 無料 |
| 会場選びサポート | 人数・エリア・予算に応じた会場候補の整理 | 2万円 |
| 台本作成サポート | 当日の進行表・司会台本の作成 | 3万円 |

### 10.1 企画の無料相談

#### 見出し案

```text
まずは無料で、企画内容を一緒に整理します
```

#### 内容

- どんな会にするかの壁打ち
- ゲーム・交流企画のアイデア相談
- 景品の方向性相談
- 会場条件の整理
- 当日の大まかな流れの相談

#### 文案例

```text
「何を準備すればよいかわからない」「毎年同じ内容でよいのか迷っている」といった段階からご相談いただけます。
参加人数、予算、会の目的を伺いながら、実施しやすい企画の方向性を一緒に整理します。
```

---

### 10.2 会場選びサポート

#### 見出し案

```text
条件に合う会場候補を整理します
```

#### 内容

- エリア、人数、予算の整理
- 着席・立食・個室・貸切条件の確認
- マイク、プロジェクター、音響などの設備確認
- 候補会場の比較
- 予約前に確認すべきポイントの整理

#### 文案例

```text
人数、エリア、予算、必要設備をもとに、候補会場を整理します。
「先生方が集まりやすい場所か」「会の雰囲気に合っているか」「当日の進行に必要な設備があるか」といった観点も含めて確認します。
```

---

### 10.3 台本作成サポート

#### 見出し案

```text
当日の進行表・司会台本を作成します
```

#### 内容

- 開会から閉会までのタイムテーブル
- 司会コメント
- 代表挨拶・乾杯・締めの挨拶の前後導線
- 企画・抽選会・景品紹介の流れ
- 幹事・司会者向けの進行メモ

#### 文案例

```text
当日の流れを整理し、司会担当者が迷わず進められる進行表・司会台本を作成します。
挨拶、乾杯、歓談、企画、締めの流れを事前に見える化することで、幹事様の不安を減らします。
```

## 14. 企画の無料相談フォーム

### 目的

まだ内容が固まっていない人向けのフォーム。  
入力負担は軽めにして、相談ハードルを下げる。

### 項目案

| 項目 | 必須/任意 | 入力形式 |
|---|---|---|
| お名前 | 必須 | テキスト |
| メールアドレス | 必須 | メール |
| 所属団体・支部名 | 任意 | テキスト |
| 士業・団体種別 | 必須 | 選択式 |
| 予定しているイベント種別 | 任意 | 選択式 |
| 想定参加人数 | 任意 | 選択式 |
| 開催予定時期 | 任意 | 選択式 |
| 相談したいこと | 必須 | チェック式＋自由記述 |
| 初回面談の実施方法 | 必須 | オンラインでの初回面談であることの確認 |
| 希望連絡時間帯 | 任意 | テキスト |

### 相談したいこと

- 何を企画すればよいか相談したい

- 景品やゲームのアイデアがほしい

## 19. 制作・運用上のポイント

### ページ制作

- デザイン・構成は共通化する
- 士業別に差し替えるのはタイトル・冒頭・イベント例・一部文言のみ
- 初期は弁護士会向け、税理士会向けの2本で検証する
- フォームは共通URLでもよいが、流入元LPが分かるようにする

### フォーム運用

フォーム送信時に、以下を取得できるようにする。

- どの士業向けLPから来たか
- どのプランに興味があるか
- イベントの時期
- 想定人数
- 相談内容

可能であれば、フォームの hidden 項目で `source_page` や `profession_type` を保持する。

### 営業運用

営業側は、相手に合わせて個別URLを送る。

例：

- 弁護士会関係者には `/shigyo-event/lawyer/`
- 税理士会関係者には `/shigyo-event/tax-accountant/`

ユーザーにはゲートウェイを見せず、「自分たち向けに作られたページ」と感じてもらう。

## 20. 現時点の結論

初期版は、以下の構成で進める。

> ゲートウェイ＋弁護士会向けLP＋税理士会向けLP  
> プランは、無料相談・会場選び2万円・台本作成3万円の3つ  
> フォームはプラン別に3本作成  
> 営業側が相手に合わせて個別URLを送る  
> ユーザーには、自分たち向けに作られたLPだと感じてもらう

この構成であれば、初期工数を抑えつつ、士業団体向けの営業検証ができる。  
反応が取れた業種から順に、社労士会・司法書士会・行政書士会・不動産鑑定士協会などへ横展開する。
